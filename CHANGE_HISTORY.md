# История изменений

## 2026-11-20 — Реальный RAG: корпус, BM25 и WebLLM

- Добавлен `corpus.js` (Node.js): читает `data/BankChurners.csv`, превращает каждую строку в русскоязычное описание клиента и сохраняет `data/corpus.json` — 10 127 документов `{ id, text, meta }` (в meta — статус, ключевые признаки и оценка оттока из датасета).
- Добавлен `app/bm25.js`: собственная реализация BM25 (k1 = 1.5, b = 0.75, IDF Robertson, постинг-листы). Предобработка: нижний регистр, без пунктуации, русские стоп-слова, нормализация ё→е и форм статуса («ушли» → «ушёл»). Поиск по 10 127 документам — миллисекунды.
- Добавлен `app/llm.js`: формирует промпт по спецификации и вызывает WebLLM (модель `Qwen/Qwen2.5-3B-Instruct-q4f16_1-MLC`, запасная Qwen2.5-1.5B; ответ стримится в чат). При недоступности WebGPU/CDN автоматически включается mock-провайдер. Таймаут вызова — 30 секунд.
- Добавлен `app/config.js` (topK, провайдер, модель, лимиты); `app.js` переведён на ES-модули: загружает корпус, строит индекс, инициализирует модель, показывает прогресс; источники отображают оценку BM25, статус и оценку оттока. Удалены заглушки поиска и ответа из `app.js`.
- Добавлены `package.json` (без зависимостей), `tests/search.test.js` (6 тестов BM25) и `benchmark/` (набор вопросов с критериями релевантности, метрики Recall@5 / Precision@5 / MRR, результаты в `benchmark/results.json`).
- Выбор модели: Qwen2.5-3B-Instruct-q4f16_1 — компактная (~2 ГБ в квантизации 4 бита), при этом заметно лучше Llama-3.2-3B понимает русский, что критично для русскоязычного корпуса и запросов.
- Исправлен баг инициализации: первый чат создавался до загрузки и не становился активным из-за ранней блокировки переключения чатов — отправка запроса падала; активный чат теперь создаётся всегда.
- Добавлен `app/probe.html` — страница-пробник для быстрой проверки WebLLM на устройстве (WebGPU → импорт → загрузка модели → генерация, результат `WEBLLM_OK` / текст ошибки).
- Исправлена загрузка WebLLM: пакет в npm переименован из `@mlc-ai/webllm` в `@mlc-ai/web-llm`, старый ID отдаёт 404 через CDN. Библиотека теперь подключена локально (`app/vendor/web-llm.js`, версия 0.2.89), CDN — запасной вариант; ID моделей обновлены под новый каталог (без префикса `Qwen/`).
- Проверка в браузере с WebGPU (встроенный браузер, AMD GPU): модель Qwen2.5-1.5B скачалась с Hugging Face за ~20 с, движок создан, генерация работает; полный сценарий приложения на Qwen2.5-3B вернул ответ модели с потоковым выводом и источниками BM25.
- Таймаут ответа модели увеличен до 60 с (первая генерация в Edge превысила 30 с из-за компиляции шейдеров WebGPU): при обрыве по таймауту частичный ответ сохраняется, генерация прерывается через `interruptGenerate`, чтобы движок не оставался занят.
- Сквозная проверка в Edge на машине пользователя: запрос «Кто из похожих клиентов ушёл…» (карта Platinum, пол мужской) → BM25 вернул 5 ушедших клиентов с оценками, Qwen2.5-3B сформировала ответ с причинами риска и рекомендациями по удержанию.
- В `README.md` добавлен раздел «Повторить проверку» с эталонными результатами (`npm test` 6/6, benchmark: Recall@5 ≈ 0.68, Precision@5 ≈ 0.84, MRR = 1.00) и описанием эталонов релевантности.
- Системный промпт уточнён: на вопросы вне темы удержания (приветствия, общие темы) модель отвечает коротко и вежливо возвращает разговор к задаче, вместо разбора документов; шаблон в `spec/tech/rag.md` синхронизирован.
- Скрипт запуска заменён: `npm run serve` / `npm run server` теперь используют `serve.js` — статический сервер на Node.js без зависимостей (команды `python` нет в PATH на Windows, `python -m http.server` падал с ошибкой). Проверено: отдача `index.html`, `corpus.json`, `vendor/web-llm.js` с корректными MIME-типами, защита от выхода за корень проекта.
- Проверки: `node corpus.js` — корпус пересобран; `npm test` — 6/6 проходят; `npm run benchmark` — среднее Recall@5 0.682, Precision@5 0.840, MRR 1.000. Основной сценарий пройден в браузере через локальный сервер: корпус загружен, поиск вернул 5 похожих клиентов 45 лет с картой Platinum, источники показаны с оценками BM25 и оценкой оттока; без WebGPU приложение корректно перешло на mock-провайдер.
- Обновлены `spec/tech/architecture.md`, `spec/tech/rag.md`, `README.md`.
