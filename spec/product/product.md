# Продукт

## Название

Помощник по удержанию клиентов

## Пользователь

Менеджер по работе с клиентами банка.
Работает с базой держателей кредитных карт.
Хочет понимать, кто из клиентов рискует уйти,
и какие действия помогали удержать похожих клиентов.

## Задача пользователя

Быстро получить ответ на вопрос:
- «Почему этот клиент может уйти?»
- «Что делали с похожими клиентами?»
- «Насколько высокий риск оттока?»

Без приложения менеджер вручную просматривает таблицы
и не видит связи между признаками клиента и его уходом.

## Ценность

- Менеджер быстрее понимает причину риска.
- Получает рекомендацию на основе реальных случаев.
- Может приоритизировать клиентов по вероятности оттока.

## Источник данных

Credit Card Customers (Kaggle).
Таблица с признаками клиентов и целевой переменной
«ушёл / остался».

## Что делает приложение

1. Принимает вопрос менеджера на естественном языке; форму характеристик клиента можно заполнить частично или не использовать.
2. Объединяет вопрос с указанными в форме признаками клиента.
3. Если система не может определить признаки клиента ни в форме, ни в тексте вопроса, просит менеджера добавить данные.
4. Ищет похожие описания клиентов через BM25.
5. Передаёт найденные случаи в LLM.
6. Возвращает ответ с рекомендацией и списком источников.

Форма включает клиентские признаки из `BankChurners.csv`: профиль, отношения с банком, активность, транзакции и использование кредитного лимита. Идентификатор клиента, целевой статус оттока и готовые выходы классификатора не запрашиваются.
Для удобства менеджер может вводить основные признаки или включить подробные поля на широком экране; на мобильном показывается только основной набор. Форма остаётся необязательной, а значения полей сохраняются при переключении режима.

## Что приложение не делает

- Не обучает модель машинного обучения.
- Не хранит персональные данные реальных клиентов.
- Не заменяет решение менеджера — только подсказывает.

## Метрики успеха

- Benchmark: Recall@5 по релевантным клиентам.
- Ответ содержит минимум один источник.
- Основной сценарий проходится без ошибок.
