# Сценарии

## Основной сценарий

**Название:** Поиск похожих клиентов с высоким риском оттока

**Актёры:** Менеджер по удержанию, система

**Предусловие:** Приложение запущено, корпус клиентов загружен.

**Шаги:**

1. Менеджер вводит запрос:
   «Клиент 45 лет, доход $60K, карта Platinum,
   транзакции упали на 40% за квартал.
   Кто из похожих ушёл и что с ними делали?»
2. Система разбирает запрос и ищет релевантные описания через BM25.
3. Система формирует промпт с найденными случаями.
4. LLM возвращает ответ: причины риска и рекомендации.
5. Интерфейс показывает:
   - текст ответа;
   - список найденных клиентов с оценками BM25;
   - вероятность оттока, если она есть в данных.

**Постусловие:** Менеджер получил ответ и видит источники.

**Проверка:** Пройти сценарий вручную, убедиться,
что ответ содержит хотя бы один источник.

---

## Альтернативный сценарий 1

**Название:** Пустой результат поиска

**Шаги:**

1. Менеджер вводит запрос, по которому нет похожих клиентов.
2. Система сообщает: «Похожих клиентов не найдено».
3. Предлагает изменить формулировку.

**Проверка:** Ввести заведомо несуществующий запрос.

---

## Альтернативный сценарий 2

**Название:** LLM недоступна

**Шаги:**

1. Менеджер отправляет запрос.
2. Поиск BM25 возвращает результаты.
3. Вызов LLM завершается ошибкой.
4. Интерфейс показывает найденных клиентов без текста ответа
   и сообщает: «Не удалось сформировать ответ, попробуйте позже».

**Проверка:** Отключить API-ключ или сеть, повторить запрос.
