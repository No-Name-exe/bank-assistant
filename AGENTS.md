# Правила репозитория

Инструкция для кодингового агента (Cline) и участников команды.

## Перед изменением кода

1. Прочитай:
   - `README.md`
   - `spec/product/product.md`
   - `spec/product/scenarios.md`
   - `spec/tech/architecture.md`
   - `spec/tech/rag.md`

2. Если задача меняет поведение приложения —
   сначала обнови соответствующий файл в `spec/`.

3. Убедись, что изменение соответствует основному сценарию
   из `spec/product/scenarios.md`.

## После изменения кода

1. Запусти тесты: `npm test`
2. Прогони benchmark: `npm run benchmark`
3. Обнови `CHANGE_HISTORY.md`:
   - что сделано
   - зачем
   - какие проверки пройдены
4. Сделай коммит с осмысленным сообщением на русском.

## Запрещено

- Менять код без обновления спецификации, если поведение изменилось.
- Коммитить без обновления `CHANGE_HISTORY.md`.
- Добавлять зависимости без обсуждения с командой.

## Зоны ответственности

- **BM25 и RAG** — корпус, индекс, поиск, benchmark.
- **Интеграция** — связка интерфейса, поиска и LLM.
- **Продукт и интерфейс** — сценарий, UI, документация продукта.

Все участники понимают общий путь запроса и умеют запустить проект.
